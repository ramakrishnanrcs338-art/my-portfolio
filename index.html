Project overview

The application collects information such as fitness goals, available equipment, and available time, then requests a personalized plan through an AI API. PHP handles the web application logic, while MySQL stores relevant user and plan information.

Key features

  • User inputs for fitness goals, time, equipment, and preferences.
  • AI-generated workout recommendations and guidance.
  • Workout video/search references where available.
  • Database-backed storage for users and generated plans.
  • Responsive web interface.
